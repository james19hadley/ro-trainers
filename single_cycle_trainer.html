💡 3. Solving Steps & Gotchas

3-Step Solving Algorithm:

  • 1. PC Calculation: Sequential (PC + 4 → PC Mux 0, PCSrc = 0) or Branch/Jump (BTA → PC Mux 1, PCSrc = 1).
  • 2. Registers & ALU: Which registers are read? Second ALU input: Register RD2 (ALUSrc = 0) vs Immediate (ALUSrc = 1).
  • 3. Write-Back (WB): From ALU (ResultSrc = 00), from Memory (ResultSrc = 01 for lw/lb), or PC + 4 (ResultSrc = 10 for jal). Stores and branches disable write-back (RegWrite = 0).

Common Gotchas:

  • Branch Not Taken: If condition is false, PCSrc = 0 and PC advances via PC + 4. The BTA wire is inactive.
  • Stores & Don't Cares: Stores do not write to registers (RegWrite = 0), so ResultSrc = X. Unused immediates are also ImmSrc = X.
  • Byte vs Word: lb/sb share datapath wires and control signals with lw/sw; byte masking is handled inside the memory controller via funct3.
